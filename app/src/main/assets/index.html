Safety

Backup and restore

Orders are stored by the browser on this tablet — there is no file on disk until you save a backup. Clearing Chrome's browsing data would erase them.

The backup is in your Downloads folder and is named belles-….json. If the picker opens Photos instead of your files, use Paste a backup instead.

Open the belles-….json from the Files app, select all, copy, then paste it here. Nothing is changed until you press a button below.

Danger zone

Deletes every order on this tablet. The shop password is required, and a backup file is saved to Downloads before anything is removed. Products, schools and departments are kept.
